# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **private vulnerability reporting**: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Include what you found, the version affected, and steps to reproduce. You can expect an acknowledgement within a few days. Fixes ship in the next release, and you will be credited if you want to be.

## Supported versions

Security fixes go into the latest release. Please check that the problem still happens on the newest version before reporting.
