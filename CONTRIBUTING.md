# Contributing

Thanks for helping. A few ground rules keep things quick for everyone.

- **Open an issue first** for anything bigger than a small fix, so we can agree on the approach before you spend time on it.
- **Keep changes small and focused.** One topic per pull request, with a clear description of what changed and why.
- **Test what you change.** Run the project's build and tests (see the README) and add a test for new behavior where it makes sense.
- **Match the existing style.** Follow the formatter and linter configuration in the repository.
- **Report security problems privately.** See [SECURITY.md](SECURITY.md). Do not open a public issue for a vulnerability.
- **Licensing.** By contributing you agree your work is licensed under the same license as the repository.

Questions are welcome in Discussions where they are enabled, or as an issue.
